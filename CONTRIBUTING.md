# Contributing to CutStock

Thanks for your interest in improving CutStock!

## How you can help

- **Bugs and ideas:** open an [issue](https://github.com/orohde/CutStock/issues/new/choose).
  A precise description, screenshots, or an exported project help a lot.
- **Questions:** use [Discussions](https://github.com/orohde/CutStock/discussions).
- **Translations and wording:** suggest corrections in an issue.

English or German is fine.

## Source code and pull requests

This repository holds the project page, releases, and issue tracker. The source
code of CutStock is not published, so there is nothing to send pull requests
against. If you've found a problem, please describe it in an issue -- the fix
will be made in the main codebase and shipped with the next release.

## Commercial licensing

CutStock is free for noncommercial use. Using it in a business requires a
commercial license -- please request one on
[cutstock.app](https://cutstock.app/en/#download) instead of opening an issue
or discussion.
